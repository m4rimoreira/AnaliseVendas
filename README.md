# Análise de Vendas de E-commerce
Projeto demonstrativo com **dados 100% sintéticos** gerados por Python. Calcula faturamento, ticket médio, vendas mensais e produtos mais rentáveis; exporta CSVs e gráfico PNG.

## Executar
```bash
pip install -r requirements.txt
python main.py
```
O programa gera `dados/vendas_ficticias.csv` na primeira execução e salva os resultados em `resultados/`.

## Habilidades
Limpeza e agregação de dados com Pandas, análise exploratória e visualização.

> Os resultados são ilustrativos, não representam uma empresa real.
